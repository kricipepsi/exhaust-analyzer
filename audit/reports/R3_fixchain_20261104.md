severity: HIGH
kind: correctness
anchor: `labs/vinlab/vinlab/data/wmi.csv` — "JTE,Subaru,BELGIUM,modern", "JTM,Subaru,BELGIUM,modern", "KNE,Hyundai,SOUTH KOREA,modern"
claim violated: F-C6-2 (`audit/reports/R1_C6_20261017.md:44`): `wmi.csv` must name the true manufacturer for in-scope WMIs. Also `labs/vinlab/docs/PRD_VINLab.md:126-127`, "WMI → brand/country resolution". T-VINA-5 R1 deliberately changed only the five P1 rows.
repro: `python -m pytest -q audit/scratch/R3/test_r3_probes.py -k viol_r3_2`
probe:
```python
@pytest.mark.parametrize("vin,engine_brand", [("JTEHH20V000092225","TOYOTA"),("JTMDEREV00D119221","TOYOTA"),("KNEDC221246348997","KIA")])
def test_viol_r3_2_wmi_make_matches_engine_owner(vin, engine_brand):
    d = decode(vin)
    code = vinlab._get_decoder(vinlab._DEFAULT_DATA_DIR)._resolve_engine(d.vin, d.make, [])["engine_code"]
    assert _extract_brands(code) == {engine_brand}      # TecDoc 1Q2019 extract: the code's only owner

```
observed: `AssertionError: assert 'SUBARU' == 'TOYOTA'` (×2) and `assert 'HYUNDAI' == 'KIA'`. The real-VIN corpus (`c6_lib.real_vins`, 1,364 VINs) has JTE 6, JTM 5 and KNE 13 VINs. Every decoded one gets the wrong make, and the decode then reaches a Toyota or Kia `vref.db` row through a code-only lookup. Audit-r2 has the same output, so the defect is older than the chain and was not missed by it as a regression.
expected: the make is the brand that the independent TecDoc 1Q2019 extract (`labs/vinlab/tools/data/tecdoc_1q2019_engine_extract.csv`) gives as sole owner of the resolved engine code: `1AZ FE` and `3ZR-FAE` belong to TOYOTA, `A3E` to KIA. Toyota-built Subaru rebadges (Trezia 2011+, Solterra 2022+) fall outside the 1990-2010 scope.
