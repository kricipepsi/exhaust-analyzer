## 1. Instrument

| step | script | output | mechanism · unit · population · blind spot |
|---|---|---|---|
| reachability | `cover.py` | `coverage_lines.json` | coverage.py `executed_lines` · source line · the owning suite run in an isolated copy, lines inside each target `def` · line-level only: a short-circuited operand on an executed line counts as executed |
| census | `mutate.py` | `mutants.json` | AST walk of the target function · one mutant = one site × one operator · sites whose enclosing statement's first line was executed · string-literal "enum" values (`"LEAN"`) are **not** mutated; only `Enum` member attributes resolved in module globals are |
| matrix | `run_matrix.py` + `p4_lib.py` + `p4_guard.py` | `matrix.json` | owning suite's full `python -m pytest` per mutant, in one of 4 copies of the tree · mutant outcome · `mutants.json` · equivalence is not decided by the tool |

**Operators** (one condition per mutant):
- `CMP`: flip one operator of a (possibly chained) comparison.
- `NUM`: int ±1, or float ±1 ulp (`math.nextafter`).
- `BOOL`: swap `and`/`or` at one junction.
- `RET`: replace a computed return with `None`, or negate a bool constant.
- `GUARD`: delete an exit guard (`if c:` → return/raise/continue/break, with no `else`). **Only single-condition
  guards** get this operator. Compound guards are mutated per condition by `CMP`/`BOOL`, never deleted whole.
- `ENUM`: swap an `Enum` member for the next member of the same Enum.

**Isolation:** `shutil.copytree` of the repo, excluding `.git .venv-audit Vault audit v3 graph research …`.
Each run sets:
- `PYTHONPATH = scratch + copy/labs/*`. `apps/wired` is left off on purpose: it would make `fl_tasks`/`v7`
  importable and change the comlab baseline.
- `PYTHONDONTWRITEBYTECODE=1`. Without it, a same-size mutant written in the same second as the restore
  reuses a stale `.pyc`.
- `--hypothesis-seed=0`, and `.hypothesis/` is wiped before every run.

**Outcomes:**
- `KILLED`: at least one new failure whose exception is `AssertionError` or pytest `Failed`.
- `KILLED-WRONG-REASON`: new failures, all of them crashes, including import/collection errors.
- `SURVIVED`: no new failure.
- `TIMEOUT`: over 120 s for comlab/gaslab, 60 s for ui/vinlab.

Failures already present on the unmutated copy (the 2 comlab collection errors) are excluded.

**Sampling:** a target with more than 150 mutants gets a seeded sample of 150, using
`random.Random("20261026:<target>")`. The populations are in the table in §2.
