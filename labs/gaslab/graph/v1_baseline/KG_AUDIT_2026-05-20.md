## Health Issues

### ISSUE-1 · Flat ID namespace — no `repo`/`local_id` fields  
**Severity: Medium (cross-graph risk)**

GASLab node IDs are flat strings: `gas_wiki_gaslab`, `gas_wiki_brettschneider_equation`.  
OBDLab uses namespaced IDs: `out1a::chunk_01a_obdlab_kg_wiki_obdlab_module_wiki`.

Neither graph has a `repo` or `local_id` field — GASLab has none at all; OBDLab has them on 496/506 nodes.

**Impact:** No collision protection if the two graphs are merged. A future `merge-graphs` call across OBDLab + GASLab would require a namespace prefix step first. ID `gas_wiki_lambda` and a hypothetically extracted `obd_lambda` would be treated as separate nodes even if they refer to the same concept — no deduplication possible without explicit mapping.

**Fix target:** Before any cross-graph merge, add a `namespace` field to all GASLab nodes (`gaslab`) and OBDLab nodes (`obdlab`). Alternatively, prefix all GASLab IDs to `gaslab::<id>` at merge time.
