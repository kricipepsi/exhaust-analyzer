## 7. `overlay/cylinder_heuristic.py` — `infer_cylinder`

Returns a frozen `CylinderHint(count, config, induction, source)`; `count == 0` means
unresolved. Fires only when `cylinder_count == 0` after CSV + `vref.db`. Brand dispatch
table (`_BRAND_DISPATCH`) routes to per-manufacturer rules:

### Brand(s): BMW
- **Rule sketch**: `[NBMS]XX` family digit → cyl; turbo families {N54,N55,B58,S55,S63}; displacement tiebreak

### Brand(s): Hyundai/Kia
- **Rule sketch**: `G[n]` → second char is cylinder digit

### Brand(s): Honda
- **Rule sketch**: J-series ≥ 3.0 L → V6; D/B/F/K/R/J/L → I4

### Brand(s): Toyota
- **Rule sketch**: family-prefix sets (I4/V6/V8)

### Brand(s): Volvo
- **Rule sketch**: `B[n]` digit = cyl; `T` suffix → turbo

### Brand(s): Mercedes
- **Rule sketch**: `MXXX` code → table lookup

### Brand(s): VW/Audi/Skoda/Seat
- **Rule sketch**: displacement bands + brand-aware induction

### Brand(s): Nissan
- **Rule sketch**: family-prefix sets (I4/V6/turbo-I4)

### Brand(s): Mitsubishi
- **Rule sketch**: leading digit = cyl

### Brand(s): Mazda
- **Rule sketch**: `[BFKP]n` → I4

### Brand(s): Subaru
- **Rule sketch**: `EJ/FA/FB/EE` → BOXER_4; `EZ` → BOXER_6

### Brand(s): Renault/Dacia
- **Rule sketch**: family table (I4/I3)

### Brand(s): PSA (Peugeot/Citroen)
- **Rule sketch**: `XU/ES/EW` → I4

### Brand(s): unknown brand
- **Rule sketch**: displacement-only fallback

Displacement fallback bands (`_displacement_fallback`): ≤1.2 → I3, ≤2.5 → I4, ≤3.5 →
V6, ≤5.0 → V8, >5.0 → V12. Config vocabulary `_CONFIG_VOCAB` (I3/I4/I5/I6/V6/V8/V10/V12/
BOXER_4/BOXER_6/ROTARY/W12) is aux data — `config` is **not** stored on `VinDNA`; it
feeds only `number_of_banks` (V/W/Boxer → 2) and the induction default.
