## 7. Downstream Integration Points (consumers)

VINLab produces; COMLab mirrors `VinDNA` and **projects** it into per-lab DNA views.
The named consumers (signal/noise rule):

### `VinDNA` field: `air_metering_strategy`
- **Consumer**: OBDLab VE routing branch (via `ObdLabDnaView`)
- **Status**: live

### `VinDNA` field: `induction_type`
- **Consumer**: OBDLab `FAULT_VE_SENSOR_SKEW` classifier; cylinder/turbo logic
- **Status**: live

### `VinDNA` field: `upstream_o2_type`
- **Consumer**: OBDLab O2 normalisation path
- **Status**: live (enum-mirror realign pending, COMLab-D)

### `VinDNA` field: `stress_idle_rpm_target`
- **Consumer**: OBDLab `STRESS_IDLE` bucketing target
- **Status**: live

### `VinDNA` field: `confidence`
- **Consumer**: OBDLab three-branch DNA-RPM gate
- **Status**: live

### `VinDNA` field: `engine_displacement_liters`
- **Consumer**: OBDLab VE formula denominator
- **Status**: live

### `VinDNA` field: `number_of_banks` / `cylinder_count`
- **Consumer**: Bank-2 null contract; UI field gating
- **Status**: live

### `VinDNA` field: CoC targets (`target_lambda_v112`, `co_low_idle`, `co_high_idle`, …)
- **Consumer**: GASLab CoC threshold tables (via projector)
- **Status**: emitted (T-DNA-4 formalized the top-level CoC fields); projector path fix is COMLab-C (Stage 4)

### `VinDNA` field: `rated_rpm`
- **Consumer**: OBDLab RPM ceiling (projector reads it)
- **Status**: **live — emitted by `VinDNA` since T-DNA-3**

### `VinDNA` field: `model`
- **Consumer**: DTCLab mirror requires it
- **Status**: **kept-empty (no field), T-DNA-5** — DBS shows no within-engine-code variance; DTCLab mirror relaxed via COMLab-D

### `VinDNA` field: `euro_emission_category` / `resolved_horizon`
- **Consumer**: era-conditioned routing context
- **Status**: live

> **Cross-lab note:** COMLab and DTCLab mirror `VinDNA`'s types locally and reconcile
> **up to** this contract. VINLab is never blocked on them. Where the projector and
> `VinDNA` disagree on nesting (CoC, emissions), the fix is the paired COMLab-C path
> change plus the T-DNA-4 contract amendment — not a VINLab change made unilaterally.
