## 13. Forbidden Patterns (VINLab-specific)

### Pattern: `from gaslab/obdlab/dtclab/comlab/symptomlab import …`
- **Enforcement**: DNA-family import boundary (one-way: `dnalab → vinlab`)

### Pattern: SQL string outside `db/tecdoc_query.py`
- **Enforcement**: H8 SQL-isolation

### Pattern: Numeric literal without a `# source:`/`# wiki:` comment
- **Enforcement**: code-review gate

### Pattern: Network or MySQL call at runtime
- **Enforcement**: offline-runtime constraint (data baked into `vinlab/data/`)

### Pattern: New `VinDNA` field without a named consumer
- **Enforcement**: signal/noise rule — field does not ship

### Pattern: Expanding `_BRAND_DISPATCH`/`_MERCEDES_TABLE` without a follow-up task
- **Enforcement**: T-VL-7 scope lock

### Pattern: Re-running graphify against `graph/`
- **Enforcement**: frozen verified artefact; not in the inner loop
