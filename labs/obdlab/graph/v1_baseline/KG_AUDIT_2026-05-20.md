### ISSUE-2 · Community fragmentation — 135 thin communities  
**Severity: Medium**

179 communities total. 135 have 1–2 nodes. The largest hub (community 0) contains only 35 nodes. The graph is a forest, not a network — clusters exist but are not bridged.

**Community size distribution:**

| Size | # Communities |
|---|---|
| 1 node | ~100 |

| 3–5 nodes | ~25 |

**Impact:** `cross_references`, `maps_to`, and `differential_diagnosis_of` edges are sparse (18, 18, 7 respectively). These are the inter-cluster bridges. Traversal from a fault profile to a related PID concept to a code entity will dead-end.

**Fix target:** Add cross-cluster edges for nodes that semantically bridge communities — especially between fault profile nodes (community 0–6) and their PID/enum targets.
