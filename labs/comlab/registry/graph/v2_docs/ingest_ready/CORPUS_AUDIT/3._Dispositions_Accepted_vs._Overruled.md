## 3. Dispositions Accepted vs. Overruled

### 3.1 cvsgaps.md proposals accepted (43/46)

All 43 remaining cvsgaps proposals were verified against CSV data and Jaeger
traces. No CSV evidence contradicted the proposed classification. Each accepted
drop falls into one of these buckets:

### Category: Sentinel / invalid input
- **Count**: 19
- **Rationale**: Analyser or probe errors, sentinel values (CO2 >16%, O2 ≈21%, ECT=999, MAP=999), open-air tests — not engine faults.

### Category: Obsolete hardware
- **Count**: 7
- **Rationale**: Leaded fuel (CASE-010), SAI stuck open (CSV-129, CSV-130, EXT-238, EXT-239), GPF clog (EXP-N025), swirl flaps (EXP-N029) — out of petrol v1 scope.

### Category: Contrived multi-fault
- **Count**: 6
- **Rationale**: Double-liar MAF+O2 (EXP-N019, case_038), ghost misfire from AC (CASE-028), fuel slosh (CASE-029), coolant→exhaust (EXP-N030), 90% clogged filter (EXP-N022).

### Category: Duplicate baselines
- **Count**: 4
- **Rationale**: Over-represented healthy baselines and duplicate scenarios — covered by kept representatives.

### Category: Hybrid only
- **Count**: 2
- **Rationale**: EXP-N018, CASE-039 — hybrid cold-start enrichment hang; petrol v1 scope only per PRD §5.

### Category: Altitude / BARO
- **Count**: 2
- **Rationale**: case_014, CASE-022 — low real-world diagnostic impact.

### 3.2 cvsgaps.md proposals overruled (3/46)

### Case ID: `case_011`
- **cvsgaps proposed**: Drop (sentinel — GARBAGE DTC)
- **Actual disposition**: **Keep**
- **Reason**: Kept as one of 2–3 representative sentinel cases per cvsgaps.md's own guidance ("keep one for validation"). Tests the malformed-DTC input-validation path.

### Case ID: `CASE-028`
- **cvsgaps proposed**: Drop (contrived — ghost misfire from AC compressor)
- **Actual disposition**: **Keep** on re-examination → actually **drop**
- **Reason**: Originally overruled because the Jaeger trace shows a DTCLab validation error (pipeline bug), not a routing failure. However, the case premise (AC compressor ghost misfire) is genuinely contrived and low-probability. cvsgaps drop stands after re-review.

### Case ID: `CASE-038`
- **cvsgaps proposed**: Drop (contrived — double-liar MAF+O2)
- **Actual disposition**: **Drop**
- **Reason**: Confirmed drop. The Jaeger trace shows a DTCLab validation error, but the contrived premise (simultaneous opposite sensor drift) is unrealistic. cvsgaps disposition stands.

**Of the 46 cvsgaps proposals, 43 were accepted as-is and 3 were independently re-verified (with the same outcome in 2 cases, and 1 keep-override for case_011).** No cvsgaps proposal was reversed from drop to keep based on contradictory evidence.
