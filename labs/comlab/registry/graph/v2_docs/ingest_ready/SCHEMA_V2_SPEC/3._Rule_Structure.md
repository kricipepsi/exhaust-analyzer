## 3. Rule Structure

Each rule is a JSON object conforming to the Pydantic `Rule` model in
`schema_v2.py`. One JSON file per fault family under `registry/rules/`.

### 3.1 Required Fields

### Field: `rule_id`
- **Type**: `str`
- **Description**: Unique within the family, e.g. `"LC-001"`

### Field: `fault_family`
- **Type**: `FaultFamily`
- **Description**: One of 16 enum values

### Field: `description`
- **Type**: `str`
- **Description**: One sentence describing what this rule detects

### Field: `competition_group`
- **Type**: `str`
- **Description**: Rules in the same group compete by score (typically the family name)

### Field: `passes_cases`
- **Type**: `list[str]`
- **Description**: At least one curated case ID this rule must PASS

### Field: `base_weight`
- **Type**: `float` (0.0–1.0)
- **Description**: Starting confidence weight; default 0.70

### 3.2 Optional Fields

### Field: `chemistry_evidence`
- **Type**: `list[ChemistryEvidence]`
- **Description**: Chemistry states with evidence tiers

### Field: `obd_evidence`
- **Type**: `list[OBDEvidence]`
- **Description**: OBD PID constraints with evidence tiers

### Field: `dtc_evidence`
- **Type**: `list[DTCEvidence]`
- **Description**: DTC patterns with evidence tiers

### Field: `confidence_ceiling`
- **Type**: `float` (0.0–1.0) or `null`
- **Description**: Max confidence when rule is solo in its competition group

### Field: `perception_flag`
- **Type**: `str` or `null`
- **Description**: Truth-vs-perception hint, e.g. `"perception_only"`

### Field: `precondition`
- **Type**: `str` or `null`
- **Description**: Free-text precondition, e.g. `"vvt_equipped: true"`

### Field: `source_wiki_refs`
- **Type**: `list[str]`
- **Description**: Wiki sources for this rule's thresholds

### 3.3 ChemistryEvidence

```json
{
  "state": "LEAN_MIXTURE",
  "tier": "DEFINITIVE",
  "wiki_ref": "GAS_VOCABULARY §3"
}
```

### Field: `state`
- **Type**: `ChemistryState`
- **Description**: One of 34 enum values

### Field: `tier`
- **Type**: `EvidenceTier`
- **Description**: `DEFINITIVE`, `SUGGESTIVE`, or `GATING`

### Field: `wiki_ref`
- **Type**: `str` or `null`
- **Description**: Citation for the chemistry→family mapping

### 3.4 OBDEvidence

```json
{
  "pid": "longft1",
  "operator": "ge",
  "value": 10.0,
  "tier": "SUGGESTIVE",
  "units": "%",
  "wiki_ref": "GAS_VOCABULARY §2"
}
```

Operators: `lt`, `le`, `gt`, `ge`, `eq`, `in_range`.

For `in_range`, provide `range_low` and `range_high` instead of `value`.
Ranges must satisfy `range_low < range_high`.

### 3.5 DTCEvidence

```json
{
  "dtc_codes": ["P0171", "P0174"],
  "strategy": "any_match",
  "tier": "SUGGESTIVE",
  "wiki_ref": "DTC_VOCABULARY §4"
}
```

Strategies:
- `any_match` — at least one DTC in the list is present (default)
- `all_match` — every DTC in the list must be present
- `none_present` — rule gains weight when none of the listed DTCs are present
