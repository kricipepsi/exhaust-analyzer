# Per-task progress notes

One file per completed task, named `<TASK-ID>.md`. Each file contains:

- The full `VERIFICATION GATE` block (per `_registry_skills/registry-verification-loop/SKILL.md`).
- The full `CODE REVIEW` block (per `_registry_skills/registry-code-review/SKILL.md`).
- Any unplanned follow-up rows discovered during the task.

Bulk content lives here, **not** in `REGISTRY_PROGRESS.md`. The ledger
table must stay under ~120 lines.

A task does not flip to `done` in the ledger until both blocks are clean
in the per-task note here.
