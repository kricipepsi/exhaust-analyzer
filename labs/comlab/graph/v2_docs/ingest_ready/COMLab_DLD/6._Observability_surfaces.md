## 6. Observability surfaces

The product/ops team consumes the PRD §8.4 dashboards. The DLD
specifies the queries that produce them, in terms of the §5 audit
fields.

### Dashboard: Sessions / day
- **Source**: `event:"pipeline.ok"` count
- **Aggregation**: per-day bar

### Dashboard: Fault family share
- **Source**: `event:"pipeline.ok"` group by `kv.fault_family`
- **Aggregation**: stacked area, per-day

### Dashboard: Fatal abort rate
- **Source**: `event:"pipeline.aborted"` count / total count
- **Aggregation**: per-day line + 7-day MA

### Dashboard: Aborts by code
- **Source**: `event:"pipeline.aborted"` group by `kv.error_code`
- **Aggregation**: pie/bar

### Dashboard: Degradation mode share
- **Source**: `event:"pipeline.ok"` group by `kv.degradation_mode`
- **Aggregation**: stacked area

### Dashboard: p95 stage latency
- **Source**: `event:"pipeline.ok"` `kv.stage_latency_ms.total` p95
- **Aggregation**: per-day line, with per-stage breakdown drill-down

### Dashboard: Top-10 fired rules
- **Source**: `kv.rules_truthy` rule IDs (LLD adds a `top_rule_id` field)
- **Aggregation**: bar chart, weekly

### Dashboard: Catalyst-imminent overrides
- **Source**: `kv.severity_level == "CRITICAL_IMMEDIATE_STOP"` count
- **Aggregation**: per-day, with `fault_family == "misfire"` breakdown

The first three are the v1 launch-gate dashboards. The rest are
nice-to-have for v1, required by v1.1.

### 6.1 Tracing (as-built)

Distributed tracing is wired in `comlab/observability/_tracer.py`. `get_tracer(name)`
returns a real OpenTelemetry tracer when the optional dependency **and** an
exporter/provider are configured, and a `_NoOpTracer` otherwise. The aggregator
and router open one span per pipeline stage and set attributes (resolved horizon,
degradation mode, winner `fault_id`, confidence). The shim is **no-op by default**
— zero added runtime cost when OTel is absent, so the latency envelope in §3 holds
whether or not a collector is attached. Span names mirror the §5.2 event vocabulary
so traces and structured logs correlate.
