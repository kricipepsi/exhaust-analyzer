## 10. Error-code taxonomy

Inherited verbatim from `DNALab_TO_COMLab_FLOW.md §6`; no new codes
introduced by this LLD round.

### Code: `ERR-CONTRACT-001`
- **Stage**: A.1
- **Trigger**: Pydantic validation (regex/range/missing)
- **Raised by**: `validate_payload`

### Code: `ERR-CONTRACT-002`
- **Stage**: A.1
- **Trigger**: Cross-field consistency (`air_metering_strategy` ↔ booleans)
- **Raised by**: `VinDNA._air_metering_consistency`

### Code: `ERR-CONTRACT-003`
- **Stage**: A.1
- **Trigger**: `downstream_trim_role != NONE` but `downstream_o2_present == False`
- **Raised by**: `EmissionsConfiguration._downstream_trim_role_implies_sensor`

### Code: `ERR-ABORT-001`
- **Stage**: A.3
- **Trigger**: `gas_lab_output.sample_validity not in {"VALID", "BORDERLINE"}` (GASLab not suppressed)
- **Raised by**: `run_fatal_gates_and_routing`

### Code: `ERR-ABORT-002`
- **Stage**: A.3
- **Trigger**: `obd_live_data.engine_warmed != True` (OBDLab not suppressed)
- **Raised by**: `run_fatal_gates_and_routing`

### Code: `ERR-ABORT-004`
- **Stage**: A.3
- **Trigger**: `vehicle_dna.vin_dna.confidence == "NONE"`
- **Raised by**: `run_fatal_gates_and_routing`

### Code: `ERR-ABORT-005`
- **Stage**: A.2
- **Trigger**: `vehicle_dna.schema_version < MIN_SUPPORTED_SCHEMA_VERSION`
- **Raised by**: `check_schema_version`

### Code: `ERR-VIN-400`
- **Stage**: A.1
- **Trigger**: VIN format invalid (raised inside VinDNA pydantic gate)
- **Raised by**: `validate_payload`
