## 8. COMLab Integration Points

### `DTCLabPayload` field / scorer output: `routing_tags`
- **COMLab consumer**: Fault-atlas routing; `POA_HISTORY` appended by COMLab when `GASLab.chemical_state == POA_SIGNATURE` (T-FX-3)

### `DTCLabPayload` field / scorer output: `mode_06_monitors`
- **COMLab consumer**: `DTC_CONFIDENCE_WEIGHTS` applied to produce per-monitor confidence

### `DTCLabPayload` field / scorer output: `historical_fault_context`
- **COMLab consumer**: Temporal dimension for fault ranking

### `DTCLabPayload` field / scorer output: `freeze_frame`
- **COMLab consumer**: `short_term_ft1 + long_term_ft1` for healing delta; PIDs forwarded to OBDLab as `freeze_frame_pids`

### `DTCLabPayload` field / scorer output: `confirmed_dtcs`
- **COMLab consumer**: Passed to OBDLab `AnalyticsPreconditions` gating in COMLab

### `DTCLabPayload` field / scorer output: `active_mil` / `mil_flashing`
- **COMLab consumer**: MIL severity context in COMLab report

### `DTCLabPayload` field / scorer output: `classify_top3()` → `(family, confidence)`
- **COMLab consumer**: COMLab Bayesian `combine()` (FU-1), via Wired adapter `T-DTW-1`
