## 9. Non-Functional Requirements

### Requirement: Import isolation
- **Target**: 0 cross-lab Python imports (audited in `test_dna_view.py`)

### Requirement: DTC format
- **Target**: 100% of valid OBD-II codes pass regex; 100% of invalid forms rejected

### Requirement: POA_HISTORY
- **Target**: Never emitted by `RoutingTagMapper` (convention; no automated test in v1)

### Requirement: Determinism
- **Target**: Same DTC input → same routing tag order (enum-definition order); scorer sorts `(-confidence, family)`

### Requirement: Mode $06 cache
- **Target**: At most 1 dictionary file open per distinct path (LRU-cache maxsize=4)

### Requirement: Scorer purity
- **Target**: No new numeric literal; all confidence from §16 weights × §14.2 DNA factor; no clamp before `classify_top3`
