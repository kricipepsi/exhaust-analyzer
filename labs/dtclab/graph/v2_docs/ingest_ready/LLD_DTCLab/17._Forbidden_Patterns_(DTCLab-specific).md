- **Enforcement**: File does not exist; `DTCSeverityClass` is enum-only (reserved)

### Pattern: `secondary_air_equipped` / `SAI_HISTORY`

- **Enforcement**: `PRD_4D_App.md §5` scope exclusion

### Pattern: Adding a `DTCLabPayload` field without a named COMLab consumer
- **Enforcement**: Signal/noise rule — field does not ship
