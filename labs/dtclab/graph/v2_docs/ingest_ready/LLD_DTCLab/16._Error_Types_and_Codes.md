## 16. Error Types and Codes

### Error: `DTCFormatError(ValueError)`
- **Raised when**: DTC fails `DTC_REGEX`; attributes: `code`, `mode`

### Error: `FreezeFrameIncompleteError(ValueError)`
- **Raised when**: Mandatory PID absent; attribute: `missing: list[str]`

### Error: `ValueError`
- **Raised when**: Invalid mode string (`"$03"`, `"$07"`, `"$0A"` only); invalid MID key

### Error: Pydantic `ValidationError`
- **Raised when**: `DTCLabPayload` field constraint; error codes `ERR-CONTRACT-001`, `ERR-CONTRACT-002`
