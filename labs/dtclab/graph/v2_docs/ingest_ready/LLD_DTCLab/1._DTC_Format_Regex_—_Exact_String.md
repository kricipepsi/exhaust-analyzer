## 1. DTC Format Regex — Exact String

Source: `DTC_VOCABULARY.md §2.3, §10`.

```python
DTC_REGEX: Final[str] = r"^[BCPU][0-3][0-9A-F]{3}$"
```

### Position: 1
- **Pattern**: `[BCPU]`
- **Meaning**: System: Body, Chassis, Powertrain, Network/Unknown

### Position: 2
- **Pattern**: `[0-3]`
- **Meaning**: Sub-category: 0=SAE/generic, 1=mfr-specific, 2=SAE reserved, 3=mfr-specific

### Position: 3–5
- **Pattern**: `[0-9A-F]{3}`
- **Meaning**: Hex fault code (uppercase only)

Anchored `^...$` — partial matches rejected. Invalid forms (per `test_dtc_ingestion_gate.py`):
lowercase (`p0171`), too short (`P017`), too long (`P01711`), wrong system byte (`X0171`),
lowercase hex (`P0a71`).
