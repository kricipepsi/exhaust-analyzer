# DNA_VOCABULARY — DNALab (v2)
**Status:** Current (reflects shipped `models.py`)
**Date:** 2026-06-12
**Source of truth:** `SEMANTIC_CONTRACT.md §4.3`.

DNALab is a composer and owns **no domain vocabulary of its own** — the physical enums
live in VINLab (`VIN_VOCABULARY.md`) and the symptom/environmental vocabulary in
SymptomLab (`SYMPTOM_VOCABULARY.md`). This file documents only the umbrella's envelope
keys, the version token, and the session-identity format.

---

## 1. `VehicleDNA` top-level keys (JSON contract surface, §4.3)

| Key | Type | Owner of inner shape |
|-----|------|----------------------|
| `session_id` | `str` | DNALab |
| `timestamp` | `str` | DNALab |
| `schema_version` | `str` | DNALab |
| `vin_dna` | object | VINLab (`VinDNA`) — see `VIN_VOCABULARY.md` |
| `symptom_dna` | object | SymptomLab (`SymptomDNA`) — see `SYMPTOM_VOCABULARY.md` |

Exactly five keys, snake_case. Renaming any is a breaking contract change.

---

## 2. Version token

| Token | Value | Notes |
|-------|-------|-------|
| `SCHEMA_VERSION` | `"1.2"` | module constant in `dnalab/models.py`; `from_json_payload` rejects any other value |

T-DNA-7 bumped this `1.0 → 1.1` once the upstream field-adding tasks landed; T-DNA-10 bumped it `1.1 → 1.2` for the `engine_state` wire-value rename (`won_not_start` → `will_not_start`).

---

## 3. Session-identity format

| Element | Format | Example |
|---------|--------|---------|
| `session_id` | `DNA_TX_` + 10 upper-hex chars (`uuid4().hex[:10].upper()`) | `DNA_TX_8849201AB3` |
| `timestamp` | ISO-8601 UTC, second precision | `2026-06-11T09:10:00Z` |

A caller-supplied `session_id` / `timestamp` is used verbatim; otherwise both are
auto-generated by `VehicleDNA.new`.

---

## 4. Forbidden / retired tokens

| Token | Status |
|-------|--------|
| any `VinDNA` / `SymptomDNA` inner field re-declared in `dnalab/` | forbidden — delegate to each model's `to_json`/`from_json` |
| `comlab`/`gaslab`/`obdlab`/`dtclab` imports | forbidden — only `vinlab` + `symptomlab` (in-family) |
| a `schema_version` other than `SCHEMA_VERSION` accepted by `from_json_payload` | forbidden — must raise `ValueError` |
| routing or physics literals in `dnalab/` | forbidden — DNALab is composition only |
| `load_state` (via `symptom_dna`) / `rated_rpm` (via `vin_dna`) | **present** since the T-DNA-7 round-trip — owned by the producers, never re-declared in `dnalab/` |
| `fuel_type` in the envelope | not present — stayed a proposal (COMLab-E), not a landed producer field |
