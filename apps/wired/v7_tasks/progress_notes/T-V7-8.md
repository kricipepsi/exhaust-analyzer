## Research findings (evidence summary)
- **Score computation (v2 path, the one v7 runs by default — `USE_V2_REGISTRY` defaults
  to "1"):** `registry/integration_shim.py::_score_rule` (`:519-574`) =
  `base_weight + 0.10/DEFINITIVE + 0.05/SUGGESTIVE`, clamped at `min(confidence_ceiling,
  1.0)`; `_translate_to_output` (`:785-803`) sets `confidence_score = clamped_score`
  (raw passthrough, no calibration). Range `[0,1]` (schema `response.py:101`). It is a
  **bounded additive evidence-accumulation rank score**, not a calibrated probability.
- **Score computation (legacy/v1, for completeness):** `fault_atlas_router.py:execute_triage_loop`
  Phase-5 (`:1038-1110`): `base_weight + bonus_on_dtc_match + evidence promotions
  (max(score, 0.80…)) + symptom-prior additive`, clamped at `_SCORE_CEILING=1.0`;
  assembled as `confidence_score=winner_score` (`:2200-2205`). Same character.
- **Saturation is structural:** v2 `base_weight` dist (73 rules): 0.80×20, 0.75×13,
  0.85×10…; ceilings None×28, 0.85×15, 0.80×11… A 0.80-base rule + two DEFINITIVE bonuses
  clamps to its ceiling (1.0/0.95/0.93/0.90). By design.
- **Wiki semantics (`09_calibration_confidence.md`, authoritative):** today's
  `confidence_score` is "evidence-chain completeness, not calibrated correctness"; the
  calibrated-posterior regime is an **unbuilt rework** (B.Q1), gated on the Gate-Data
  measured-real subset (`COMWIKI-12`) which does not yet exist; until then numbers are
  "expert-set priors, flagged as such." Target tiers: HIGH ≳0.80, DEGRADED 0.50–0.80,
  LOW <0.50.
- **LLD (`COMLab_LLD.md`):** defines `confidence_score: float Field(ge=0,le=1)` (§3.3,
  cited to a flow doc) + `ConfidenceLit` tier enum + `MIN_CONFIDENCE_THRESHOLD=0.70` (§6.4)
  — but does NOT define it as a calibrated posterior.
- **Downstream thresholds reading the numeric value:** 0.70 threshold-miss gate
  (legacy `:1686`) + 0.70 tier-label step (both paths `:2234`/shim `:798`) + 0.60 demotion
  cap (legacy) + `DifferentialSiblingOut.confidence_score` (UI badge, None=editor-curated).
  **No consumer reads it as a continuous calibrated probability** — only a single 0.70
  step into a 2/3-tier label. The engine's 0.70 cut already diverges from the wiki's
  target HIGH band (≳0.80).
- **Oracle-band provenance (T-V7-3):** bands cluster around the wiki's *target* HIGH_ASSURANCE
  posterior band (~0.80 ±0.10). T-V7-3 note says "derived from lab wikis + atlas"; the
  `ORACLE_TRIAGE` note records **no confidence-band provenance**. So the bands assume a
  calibrated-posterior semantics the engine doesn't emit → band B is weakly defensible.
