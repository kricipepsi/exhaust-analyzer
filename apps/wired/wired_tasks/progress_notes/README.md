# wired_tasks/progress_notes/

One file per task, named `<task-id>.md` (e.g. `T-WIRE-1.md`). Each opens with the
confirmed `## Plan` (written at task start, before any code), then gains the
`VERIFICATION GATE` and `CODE REVIEW` blocks at task end. Both gate blocks must be
clean before the task's row in `WIRED_PROGRESS.md` flips to `done`. Keep bulk
content here — never in the ledger (it must stay < ~120 lines).
