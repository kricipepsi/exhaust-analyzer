# vault-live progress notes

One file per task: `T-VLIVE-<n>.md`. It **opens with the confirmed `## Plan`**
(written at task start, before any edit), then gains the full `VERIFICATION GATE`
+ `CODE REVIEW` blocks at task end. Kept out of `VAULT_LIVE_PROGRESS.md` so the
ledger stays under ~120 lines.

A task flips to `done` in the ledger only when **both** gate blocks here are clean
(see `../../VAULT_LIVE_START_HERE.md` → Session-end checklist).
